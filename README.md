# Markup Lab

A learning project focused on improving semantic HTML, mastering the BEM methodology, building modular layouts, and experimenting with complex CSS animations. The structure and logic are designed to prepare the project for future integration into WordPress themes.

## 🚀 Project Goals

- Practice **semantic HTML structure**
- Strengthen understanding of **BEM methodology**
- Build **adaptive, modular, scalable layouts**
- Create **advanced CSS animations**
- Prepare markup for future **WordPress integration**


## 🛠️ Tech Stack

- **HTML5**
- **CSS3 / SCSS**
- **BEM (Nested / Flat)**
- **Flexbox & CSS Grid**
- **CSS Transitions & Animations**


## 🎯 Planned Features

- Multi-layer animations (parallax, fade, slide, stagger effects)
- Interactive components without JS
- Responsive grid layouts (CSS Grid + Flexbox)
- Clean BEM block architecture
- Sections prepared for WordPress templating (header.php, footer.php, loops)


## 📦 Installation & Usage
